# Mundo100Manual pipeline

Read the root WORKFLOW_MESTRE_ZE_DESMONTE.md for stages, commands and evidence. Run the Editorial preflight in the root AGENTS.md at each applicable stage, including when resuming. Read refs/CAMERA.md for camera decisions. Consult BUGS.md, the role file and the live panel.

Use the existing project folder and its state. Record the next stage before assigning work. Only one role owns each editable file. Clear agent context before a new service order. Preserve the user's approvals, actual proof and current input hashes. Final rendering requires explicit user approval after P3. Publishing is a separate action.

For a new topic, approve the skeleton, script and visual plan before processing the user's voice. Apply recipe §1 for the script, short cause-and-effect chain (§1.2, cause-and-effect style); no gap comb. For Retrocesso Causal, follow §§1.1, 4 and 8 from the skeleton through the P3 review. P1 defines visible intent. P2 proves the mechanisms and framing. P3 reviews the full preview. P4 verifies the exported file. Flow rules in `WORKFLOW_MESTRE_ZE_DESMONTE.md`: one approval package (skeleton, script, plan), voice only after the script is locked, preview checklist before the user sees any preview, stop for a direction decision after 3 P2 rounds, and `publicacao.md` plus `retrospectiva.md` before P4.
